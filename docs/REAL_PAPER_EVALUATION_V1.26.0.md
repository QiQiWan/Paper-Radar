# v1.26.0 真实论文评估方案与已完成范围

## 当前评估结论

种子集包含 3 篇真实公开论文（FNO、U-FNO、PINO）、6 条原文实验记录和 5 组不可比样本，人工标签来源见 `benchmarks/real_papers_v1`。本轮执行环境无法访问外部论文 PDF，实际本地原始 PDF 为 **0/3**；因此论文解析召回率、实验数值抽取 Precision/Recall/F1 均为**未测量**。不可比测试中的安全拦截仅用于确认规则没有放行已知冲突，无法评估真正可比实验的召回率（此种正例为 0）。不得将测试代码 100% 通过写成论文抽取准确率 100%。

## 评估工具

`tools/eval_real_papers.py` 现在提供三个独立操作：

```bash
# 只在有外网的自用计算机上按指定 arXiv URL 下载原始 PDF，不把 PDF 纳入公开发布包
python tools/eval_real_papers.py fetch --pdf-dir ./real_pdfs
# 双人独立标注空白表：不会自动把原项目的种子标签当成新增人工数据
python tools/eval_real_papers.py template --output ./annotation_work
# 依据真实下载的 PDF 评估页面召回，按需传入模型预测 JSON
python tools/eval_real_papers.py score --pdf-dir ./real_pdfs --predictions ./model_predictions.json --output ./eval_output
```

没有模型预测文件时**省略** `--predictions` 参数，输出标记为未测量。PDF 文件名采用 `{paper_id}{version}.pdf`，例如 `2010.08895v3.pdf`；解析在独立子进程执行并有时限。评估结果包括 PDF SHA-256，便于复现和检查原文版本。

### 评价指标的精确定义

| 指标 | 计算依据 | 不能推断什么 |
|---|---|---|
| 页面锚点召回率 | 标注页面中方法及数值两个锚点是否同时出现 | 不能证明行列对应正确 |
| 候选页召回率 | 已标注实验所在物理页是否被候选页检索选中 | 不能证明模型已读到完整表格 |
| 片段锚点召回率 | 候选页截断片段中是否包含两个锚点 | 不能证明模型理解单位和实验配置 |
| 数值抽取 Precision/Recall/F1 | 论文 ID、物理页、方法、数据集、指标、数值六字段严格匹配；重复预测计入精度分母 | 样本规模太小时不能代表领域整体 |
| 错误比较率 | 人工标注的不可比关系被算法错误放行的比例 | 没有可比正例时不能给出可比召回率 |

## 评估集扩展至 30 篇时的标注协议

1. **分层抽样**：覆盖算法类、材料类、时序、仿真、医学/自然科学等至少 5 类 PDF，包含双栏排版、复杂表格、附录、图文混排和低文本扫描文档；记录下载日期、版本、版权许可与 PDF SHA。
2. **双人独立标注**：先在 `annotations_A.csv`、`annotations_B.csv` 分别填写论文、页码、方法、数据集、指标、数值、单位、baseline、setting、表格行列及原文摘录，再合议冲突。空值不得自动填充为错误或正确。
3. **配对正反例**：每篇至少记录可比与不可比的样本或明确标记“无可比正例”，防止只测特异性。按论文而非证据行划分训练/验证/测试集，避免同篇信息泄漏。
4. **复现**：固定论文版本、解析器版本、检索阈值、模型名称、提示词、随机种子及费用，保存失败日志。展示样本数及置信区间或逐例错误分析。
5. **人工评判**：经原文校验的数值还要核查行列、训练预算、数据划分、单位、指标方向；与原文冲突的结论需要阻止进入自动定量比较。
