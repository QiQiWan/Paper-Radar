# Paper-Radar v1.50.0：批量科研证据流程审阅

## 核心结论

本轮已将高相关论文的 PDF 下载、全文索引、实验片段提取、人工确认和同指标跨论文对照接成一条**本地可恢复工作流**。研究人员可直接在「研究分析」页面选择论文并一次提交多篇，不必逐篇切换下载、解析与审核工具。系统保留原文 SHA256、PDF 页码和逐字校验，并提供模型降级和单篇失败隔离。

已核对的数值记录与已确认的科研结论分开保存。软件不会因为找到同名指标就推断跨研究模型优劣；CSV 和在线对照均保留“需人工确认可比性”的标识。

## 逐项实现与审阅

| 需求 | 主要改动 | 核查重点 |
|---|---|---|
| 自动筛选高相关文献 | `evidence_batch.preview` 按当前主题和问题筛选最多 12 篇论文 | 没有直接匹配时不填充无关论文，防止假相关 |
| 自动 PDF 获取 | 复用 `downloads.manager.download_selected` 的可信下载器 | 未公开可获取的 PDF 记录 `no_pdf`，继续其他论文 |
| 批量全文解析 | 复用 `fulltext.index_paper` 的本地 pypdf 页面索引 | 文件格式、加密及扫描件失败不会阻断批次 |
| 实验字段提取 | 已授权时走 `agents.research.pipeline`，其他情况走本地候选提取 | 未核对的提取结果只进入人工队列 |
| 原文定位 | 候选记录绑定 sha256、chunk_id、page、quote | 每次审核与读取重新检查 PDF 版本及原文位置 |
| 人工集中确认 | 审核面板可填写实验条件、指标、数值、基线、说明；版本号检查 | 不在原文出现的字段被拒绝，修改 PDF 后旧审核失效 |
| 跨论文比较 | 同数据集和指标的人审数值并列，PDF 位置可点击，支持 CSV | 不自动计算提升率、差值、统计显著性或结论一致性 |
| 断点续跑 | SQLite 保存批次/论文/候选/事件，异常后可恢复失败子任务 | 已确认记录不可被重试覆盖，重复执行不重复创建 |
| 运行记录 | 任务状态与模型状态分别记录，诊断 ZIP 增加 `evidence_batches.json` | 日志不包含 API 密钥、研究问题或论文全文 |
| 页面可用性 | 研究分析页新增批量入口、候选卡片和对照卡片，低频进度可展开 | 桌面和手机的组件交互可用，未出现横向溢出 |

## 新发现并收敛的问题

1. 大量候选记录的逐次 SHA256 计算会显著拖慢刷新。现对每次 HTTP 请求中的同一 PDF 缓存一次文件校验，审核仍逐条核对引用文本。
2. 人工批准后改为排除时，若留下原文锚点，容易在其他页面继续被引用。现撤销未被科研结论引用的锚点；已经被引用时要求先解除关联。
3. 模型已启用、模型实际执行和模型有可用结构化结果是不同状态。现明确记录 `model_status`，未授权或缺少 API Key 的任务只产生本地原文候选。
4. 已建立全文索引但找不到实验指标时，旧流程易误报“准备完成”。现记录 `no_experiment`，可按需重试。
5. 新建批次在同一秒内可能排序不准确。最近批次以创建时间和 SQLite 行顺序确定。

## 验收边界与不应外推的结论

- 本轮使用**隔离生成的 PDF 文件与 SQLite 数据**，测试成功不代表真实 arXiv、OpenAlex、Crossref 在用户网络环境中一定能下载。
- 对有文本层的 PDF 可抽取分段原文；扫描 PDF 需要 OCR，多栏排版和跨行表格仍可能损失字段关联。
- 浏览器自动化在当前容器的 Chromium 环境中无法进行原生地址导航，采用 `page.set_content` 挂载真实前端组件，通过 Python 桥接实际 HTTP API 完成交互。该测试能够验证组件与后端，但不等同于完整软件原生浏览器验收。
- 没有调用用户实际配置的付费模型，也没有对其 60 篇已收录论文执行真实外网下载。所有结构化模型提取测试均使用固定模拟输出，模型性能及费用尚未量化。
- 目前是**本地版功能**。公网多账号版本需再次实施身份校验、配额与 Worker 多租户隔离。
- 同指标和同数据集的 PDF 原文数值仅支持并列展示。验证跨论文可比性时，还要单独审阅评价指标定义、实验样本、划分方式、随机重复、数据尺度与计算预算。

## 下一步重点

以本地已有 60 篇研究题录为总体，从中选取 10–12 篇直接相关论文进行试点；测量真实开放 PDF 获取率、全文解析率、人工核对耗时、字段正确率和有效跨论文对照组数。每个实验数值至少保留页码、源 PDF 指纹和核对人员说明。真实试点评估达到可用水平后，再考虑将流程推广到公网研究团队工作台。
