## 2. 真实论文基准的实测边界

真实公开论文：FNO 2010.08895v3、U-FNO 2109.03697v3、PINO 2111.03794v4。人工核对的论文实验字段 **6 条**；不可比配对 **5 组**，当前全为负例。

- 使用人工金标准调用现有 `SynthesisAgent`：6 条数据保留 6/6 条引文及页码；5 个明确不可比配对中 **0 个错误生成跨论文直接比较候选**。
- 生成了 `real_paper_synthesis.md`，明确标识“人工导入且尚未由服务器原始 PDF 校验”；此报告用于检查证据链与保守对比策略。
- 本环境下载真实原始 PDF 失败，因此 **本地真实 PDF 成功解析 0/3，PDF 页码锚点召回率为 null（未测量）**；模型预测输出也未提供，模型抽取 Precision/Recall/F1 **未测量**。
- 基准内没有已核查的跨论文可比正例，**不能估算正例召回率、总体验证准确率、统计显著性或实际学术分析改进幅度**。这些属于下一轮真实论文样本扩增工作。

如在本机拥有互联网访问权并且文献使用合规，可执行：

```bash
python tools/eval_real_papers.py fetch
python tools/eval_real_papers.py score
python tools/eval_real_papers.py score --predictions your_predictions.json
```

前三项输出的 PDF 或模型指标必须由结果文件实际统计，不能使用本轮 6 条人工录入数值冒充自动解析质量。
