# Paper-Radar v1.20.0 使用手册：五入口科研工作台

## 启动与账号

公网服务仍通过专用 Web 入口运行，后端监听端口可自定义；实际对外应使用 Nginx HTTPS 代理。已有用户用原账号登录，新用户在管理员允许注册时可以选择“注册”建立账号。管理员可在“我的账号”管理状态；用户之间的论文与科研报告不共享。

本地桌面版使用原启动脚本，仍可使用 Zotero、本地 PDF 下载、模型设置及 Windows 定时任务。公网版不会访问桌面 Zotero 数据库或服务器操作接口。

## 第一步：选择或建立研究主题

登录后首先进入“工作台”。右上方的“当前研究主题”可以切换研究方向；首次使用可展开底部“管理研究主题”，填写主题名称及最多 6 组英文关键词。切换主题会同步切换论文、阅读状态和历史报告。URL 中含当前页面/主题，因此可使用浏览器返回和刷新恢复。

## 第二步：运行科研任务

点击“开始文献追踪”，进入“任务中心”。“仅检索 arXiv”用于获取近期公开题录；“一键完成科研分析”会在检索之外尝试受控 PDF 下载、解析、证据及报告。只有主动勾选“授权将有限正文片段发送至云端模型”且管理员已配置模型时，才会发生云端模型提取请求。该调用可能产生费用。

运行期间可在“当前任务进度”查看真实阶段状态、失败原因和成果信息，并在“历史执行记录”查阅之前的任务。任务由独立 Worker 运行；刷新页面不会终止后台执行。没有 PDF、模型权限或受限于来源访问时，报告应展示缺失信息，研究结论需要进一步人工核对。

## 第三步：筛选论文并记录阅读进度

点击“论文库”。搜索框支持按题名、摘要、DOI 查找；筛选器支持全部、星标、未阅读、阅读中、已读完和推荐有价值；排序可选最新、最早、题名字母序。

每篇论文可以标记星标，修改阅读状态（未读、在读、已读），或设置相关性反馈（有价值/无价值）。系统将状态保存到当前账号、当前主题的独立数据库；刷新之后仍可查看。首页的统计数字反映当前主题的论文、星标、已读和已保存报告数量。每次显示 12 篇，点击“加载更多”继续浏览。

需要阅读全文时，可通过论文卡片的 PDF/证据操作打开已经准备的全文片段，使用来源链接回到原论文。仍需遵守来源版权和 PDF 使用授权。科研数据集/指标比较必须复核实验设置与引文。

## 第四步：阅读历史报告

点击“研究报告”。每份历史报告保留创建时的独立快照，点击条目即可在线阅读；打开已有快照不会重新生成内容，也不会再次产生云端模型调用费用。需要外部归档时下载 Markdown。复杂表格可在报告区横向滚动，手机页面整体不应随表格横移。

“生成跨论文比较”会产生新的后台任务。报告只将实验条件已核验的一致记录作为比较候选，缺少数据集、基线、单位等时应明确提示，不会自动宣称跨论文性能提升。

## 第五步：维护账号和数据

“我的账号”包含修改密码与数据保护范围说明。修改密码后会话失效，需要重新登录。管理员拥有额外的账号启用、停用和任务概况权限。建议定期备份独立的 `PAPERRADAR_PORTAL_DATA` 数据目录。

## 手机端操作提示

手机底部固定显示五个入口；上方研究主题选择器贯穿页面。尽量从底部导航切换论文、任务和报告，不必连续滚过全部功能。报告表格支持局部滚动。建议通过浏览器 HTTPS 地址访问，避免在公开网络输入账号密码到非 HTTPS 服务。

## 常见情况

- 论文库没有结果：检查当前主题关键词，运行一次“仅检索 arXiv”；查看任务失败原因或来源限流情况。
- 任务一直排队：检查独立 Worker 是否启动、Web/Worker 是否共享同一个数据目录、任务配额是否耗尽。
- 论文星标消失：检查是否切换了研究主题或账号；星标是主题独立状态。
- 报告列表为空：已有报告快照只来自新版 Worker 完成的研究/综合任务；旧版动态报告不会被自动补录。
- 无法访问下载的 PDF：来源未开放、权限不足或文件超限均有可能；可在有合法权限时手动上传。
- 新版启动检查失败：在网络不可用时使用本地程序；只有经过生产签名的正式 Release 才能触发可信自动安装。
