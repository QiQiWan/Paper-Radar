# v1.48.0 使用说明

## 本地工作台

Windows 双击 `start_windows.bat`；macOS 或 Linux 执行 `./start_macos_linux.sh`。首次启动需要安装相应 Python 依赖。

从“找论文”进入检索，使用自然语言描述研究方向，模型连接成功后可生成并编辑关键词；无需模型时直接输入检索关键词即可查找论文。

新安装默认选中模型摘要和排序。首次未添加密钥时，页面提示“添加模型密钥”；点击后在“设置 → 模型服务”选择服务商、填入 API Key、阅读数据传输说明、按需授权并保存。没有授权不会自动发送论文或研究目标。

## 公网工作台

云端实验分析默认勾选；服务端模型由管理员配置 `PAPERRADAR_PUBLIC_LLM_KEY`、`PAPERRADAR_PUBLIC_LLM_BASE`、`PAPERRADAR_PUBLIC_LLM_MODEL`。普通账号不需要也不能在网页输入服务器密钥。系统未连接模型时用户可选择继续普通 PDF 解析。

## 主要操作

首页用于进入查论文、继续阅读和研究分析；“我的文献”管理收藏与 PDF；“研究分析”整理论文原文依据；“我的报告”查看、阅读和导出成果。专业设置及批量操作位于各自页面的“更多工具”。

详细功能及权限见 `docs/USER_GUIDE.md` 和 `docs/UX_AUDIT_V1480.md`。
