## 主要安全与恢复场景

1. 模拟网络断开、更新被用户关闭、服务运行中/后台检索中：原有程序仍可使用。
2. 更高版本元数据正确但附件无SHA-256、下载内容不匹配、官方来源网址不匹配：拒绝安装。
3. ZIP路径穿越、用户数据目录混入、启动协议不匹配、Python源码语法异常：安装前拒绝。
4. 本地文件备份、旧程序变更、更新成功：数据库、报告、PDF及设置保持一致；代码目录按新包替换。
5. 新版启动失败：旧程序自动回退，SQLite/设置快照可恢复；手动回退时保留用户最近新增的数据。
6. 代码替换完成但启动验证前断电：下次启动继续验证并保留回退证据。
7. 事务日志损坏或恢复失败：阻止继续启动，避免混杂代码运行。

模拟环境可以验证Updater逻辑与真实本地文件替换，不能替代发行者在GitHub上传正式资产后的在线下载、GitHub重定向及Windows文件锁行为实测。前端Chrome直接连接localhost受到环境策略限制，本轮前端页面由真实HTML/CSS/JS与离线资源组成，不声称模拟网络环境中的失败提示代表生产UI的真实状态。已用实际HTTP服务单独验证 `/api/health` 与配置接口。
