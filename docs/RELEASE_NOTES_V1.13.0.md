# Paper-Radar v1.13.0 发布说明（候选版）

更新日期：2026-11-04

本版将每日文献追踪拆分为九个 Agent：研究画像、文献发现、质量筛选、模型重排序、数据入库、中文速览、PDF 下载、报告选文和报告生成。各 Agent 使用统一输入输出契约和显式依赖编排，便于独立开发、测试和定位故障。

- 新增 `paper_radar/agents/`、独立单元测试、Agent 依赖检查和 `python -m paper_radar.agents` 命令行检查工具。
- 新增本地运行轨迹 `data/agent_traces.sqlite3`：仅保存阶段状态、耗时和有限数量指标，不保存论文正文、提示词或密钥。
- 新增 `GET /api/agents` 和“设置 → Agent 工作流”面板，用于查看职责和最近执行结果。
- 保持 `core.run_cycle()`、原网页和定时任务兼容；关键任务失败终止，非关键可选模型及下载任务失败时允许生成部分完成的报告。
- 单主题和批量检索的“部分完成”状态现在会反映辅助 Agent 故障，避免状态误报。
- 更新 README、CHANGELOG、开发文档、使用说明、发布清单和 Agent 独立研发清单。

**限制：** 本轮引入的是职责明确的任务 Agent。全文 RAG、Agent 自主规划任务、在线自动升级、分步骤断点恢复尚未实现。发布前请在 Windows 实机验证 Zotero、计划任务、模型调用及 GitHub Release 更新检查。
