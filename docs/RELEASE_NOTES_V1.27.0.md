# Paper-Radar v1.27.0 — 科研界面精简与交互整理

本次升级全面整理本地研究工作台、公网门户和桌面运行管理器。高频科研操作保留在主界面，来源、筛选、模型和日志等低频设置按需展开。原有研究数据、论文、报告、API、Agent 和任务队列不变，数据库版本不变。

## 主要变化

- 本地工作台采用“选择主题—填写关键词—检索”单一主操作，主题管理、AI 关键词建议、其他运行模式、检索数量/排序选项收纳到展开区。
- 本地设置页重组为六组：检索与报告、AI 阅读与模型、出版社数据源、PDF 下载、软件更新、运行诊断。
- 论文库及研究报告页将批量下载、导出及次级筛选收进更多操作；Zotero 将连接故障排查及次级操作收纳。
- 公网工作台把待读论文、待核验证据放到主要位置；主题配置紧贴主题切换；账号设置新建与编辑主题互斥展示。
- 公网全文证据、任务高级参数、CSV 导出及账号安全配置根据用户操作展开。
- 桌面管理器改为服务状态、打开工作台及进度优先，日志和数据位置按需展开。
- 加入界面静态合同与 Chromium 离线点击检查，并更新旧版浏览器验收工具的表单切换操作。

## 升级注意

- 从 v1.26.0 直接升级；无需执行新数据库迁移，原则上保留现有研究主题、历史报告和个人文件。
- 升级前仍建议备份应用数据目录，并停止本地或公网服务与独立 Worker，避免源码替换时任务还在执行。
- GitHub 自动发布构建流程及四平台发布策略保持不变，应用版本已同步升级为 v1.27.0。
- 本次自动化验证包括离线/模拟 API；真实第三方网络、Windows/macOS 原生安装和正式生产环境需要另外验收。
