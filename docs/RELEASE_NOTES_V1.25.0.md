# Paper-Radar v1.25.0 | 科研工作流与交互增强

本版在 v1.24.0 已有的 PDF 解析、证据复核、跨论文配对、独立 Worker 和报告快照基础上，补齐用户日常追踪文献时的工作台入口。所有新公网来源均为**按主题手动开启**。公网 OpenAlex 默认使用不带服务器密钥的免费查询；只有管理员显式配置 `PAPERRADAR_PUBLIC_ALLOW_OPENALEX_API_KEY=1` 才允许公网页面使用托管 OpenAlex 密钥，需自行控制服务额度和费用。默认新旧研究主题继续只启用 arXiv。

## 用户可以完成的具体工作

1. **管理研究主题。** 在工作台下方展开“管理研究主题”，调整名称、英文关键词以及 arXiv、OpenAlex、Crossref 三个公开题录来源。保存配置后，下一次搜索生效；旧数据及阅读标记保留。服务器维护白名单，无法通过表单输入自定义任意 URL 或出版社凭据。
2. **跨来源检索。** “任务中心 → 检索当前主题”依次在受控独立进程访问启用来源。不同来源单独限时、节流和记录状态。一个来源故障时保留其他来源结果，三个来源均失败才将检索任务标记失败。以 DOI 及来源 ID 合并重复记录，避免覆盖既有阅读标记。摘要、出版日期依赖上游元数据质量。
3. **处理待阅读论文。** 工作台显示已星标且未读完的论文数，“进入阅读清单”只列出尚未读完的星标论文。最近论文题目可直接进入论文卡片。
4. **处理待复核证据。** 工作台显示当前 PDF 指纹匹配但尚未完成复核的实验依据数量，并列出最多 5 篇待复核论文及对应起始页。点击论文可直接打开 PDF 证据与人工审核界面。更改审核记录后工作台数字同步刷新。
5. **查看并重试失败任务。** 任务中心的来源诊断区显示各来源成功、超时和故障情况；历史任务和当前详情为明确安全的失败/取消操作提供“安全重试”。系统只允许纯检索、确定性报告生成及未启用云模型的单篇分析复用历史配置；完整研究任务与云模型分析必须重新确认选项。重试是新任务，仍占用正常配额。
6. **导出实验证据账本。** 在“研究报告 → 导出实验依据 CSV”获取当前主题全部有效 PDF 实验记录和标记为未核验的导入记录，包含论文、证据 ID、实验条件、原文摘录、页码、来源、审核状态及时间。仅当前账号可访问，CSV 使用 UTF-8 BOM 并转义 Excel 公式前缀。CSV 内容可能包含论文文字和用户审核信息，分享前须检查保密与论文使用许可。

## 数据及接口变化

- `portal_workspace` 从 **v7 → v8**，追加 `topic_sources(topic_id, sources_json)`。不重建旧数据，不改变用户阅读状态、PDF、人工审核、旧报告。
- `portal_auth` 仍为 **v6**。历史报告快照不可变，修改主题不会倒写旧报告。
- `GET /api/public/topics` 增加 `sources` 和 `supported_sources`；`POST /api/public/topics` 接受可选的 `sources`；新增 `POST /api/public/topics/update`。
- `GET /api/public/dashboard` 增加 `to_read`、`pending_review` 与最多五篇 `pending_papers`；`GET /api/public/papers` 支持 `paper_id` 精确选择和 `filter=to_read`。
- 查询任务详情增加 `retryable`；新增 `POST /api/public/jobs/retry`，重试仍受账号、CSRF 与配额限制。
- 新增 `GET /api/public/evidence/export?topic_id=...` 下载账号隔离的 CSV。
- 检索任务结果增加来源级 `source_results` 和总完成状态 `state`，有成功有失败时显示 `partial`。

## 权限与使用边界

- OpenAlex 和 Crossref 在公网版仅检索题录，不自动下载其 PDF。自动开放 PDF 下载仍限制在原有 arXiv 安全路径；其他论文由用户上传已获授权的 PDF。
- 全文云模型分析继续默认关闭。用户每次显式授权后才执行，可能产生模型费用。安全重试不自动重复收费分析。
- 外部服务的真实访问成功率、外部 API Key 消耗和科研内容准确率尚未通过真实网络与真实论文测定。源码提供功能与离线回归测试，不能代替正式环境的稳定性和数据授权审查。
- CSV 证据仍需学术复核：来源原文通过核验并不保证方法、数据集、数值行列的关系全部正确。人工通过状态仅代表当前账号审核者的确认。
