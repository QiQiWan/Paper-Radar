# Paper-Radar v1.21.0 发布说明

**重点修复：** 文献来源无法访问导致任务长时间停留在检索中。新版为实际来源查询增加可终止的独立子进程、单组/总预算、来源故障诊断、全部来源失败时的状态收敛。可在本地设置调整默认 10/75 秒。

**新增科研阅读：** 桌面版和公网版都可并排查看 PDF 与原文证据；公网 PDF 由登录账号、研究主题和文件 SHA-256 联合校验，支持 HTTP Range，跨账号禁止读取。

**新增比较矩阵：** 公网研究报告把已有 SynthesisAgent 的结构化证据按数据集、指标和实验条件组织为候选矩阵，保留原始数值、基线、页码及证据级别，不自动给模型排名。

**界面修复：** 手机端比较表格局部滚动，不再撑宽整个页面。保留 v1.20 的五入口导航和所有原有工作流。

**数据迁移：** 本次无需迁移。升级前仍需停止 Web/Worker 并备份个人数据。未使用生产私钥签署 GitHub Release，也未完成 Windows/公网服务器实际验收。

详细操作参见 `docs/PORTAL_GUIDE_V1.21.0.md`，设计与边界见 `docs/DESIGN_V1.21.0.md`。
