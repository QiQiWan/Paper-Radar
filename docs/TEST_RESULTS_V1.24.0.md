# Paper-Radar v1.24.0 离线与集成验收记录

## 范围与结论

本次在 v1.23.0 的 397 项全量用例基础上，补充证据人工复核、跨论文配对、审计历史、账户/主题隔离、迁移与并发条件核验测试。完整回归命令为 `python -m pytest -q`：**413 passed in 149.72s，退出码 0**。本文档随源码包发行，不以单元测试代替生产部署或真实科学效果验证。

已执行的额外检查：

- `python -m compileall -q paper_radar tools`：通过。
- `node --check paper_radar/static/portal.js`：通过。
- `python -m tools.verify_public_deployment --smoke`：配置不变量检查通过，HTTP 冒烟返回 health=200、关闭注册得到 403、version=1.24.0。该命令没有验证真实 Nginx/systemd/公网上行链路。
- `python -m tools.eval_comparison_policy --out result.json`：**15 项人工编制的规则回归样例**全部吻合，TP=2、TN=13、FP=0、FN=0；此数据不用于说明学术准确率。
- `python -m tools.eval_real_papers score`：种子基准含 3 篇论文、6 条人工证据、5 个不可比负例。评估环境缺少原始论文 PDF 和真实模型预测，实际 PDF 页召回、实验归属准确率和模型 F1 均**未测量**。五个不可比负例对当前对比策略的命中不代表真实世界的比较准确率。
- Headless Chromium 可以启动；访问容器内 `127.0.0.1` 测试服务时被执行环境策略返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此没有得到真实浏览器端到端交互或视觉验收结论。HTTP API 专项测试和 JavaScript 语法检查已通过。

## 本版本新增回归范围

1. 工作区数据库由 v6 增量迁移到 v7，验证旧论文和主题仍可访问。
2. PDF SHA、原文引文和人审条件绑定；更改原文或替换 PDF 撤销有效复核，但审计历史保留。
3. 同指标、数据集、实验划分、单位、方向、聚合方法、训练预算和评估协议一致的正例可人工确认配对。
4. 任何关键条件冲突均阻止“人工确认可比”，显式人工否决得以记录。
5. 完整账号、主题、CSRF 和权限检查；同一账号在不同主题审核同一对证据互不覆盖。
6. 在配对审核预检查后发生并发条件更新时，写事务内重新核验当前字段及 PDF 指纹，阻止竞态写入。
7. 报告生成仍通过原有科研任务/不可变快照链路，用户复核动作本身不直接生成即时报告。
8. 用户界面由 DOM `textContent` 安全呈现复核内容，需人工触发保存与再次生成报告。
