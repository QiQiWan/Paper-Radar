# Paper-Radar v1.12.0 发布说明

2026-11-04

## 新功能

这次更新主要增加了“全文证据”阅读能力。已保存开放 PDF 的论文可以在论文库直接解析正文、查看 PDF 页码，并按原文术语查找证据。需要 AI 辅助分析时，用户主动确认后才能将选定片段发送至已配置的模型服务商；阅读卡片会标注方法、实验和局限性，并保存原文引文。

Word 和 Markdown 现在可以在原摘要简报之外附上经本地字符串核对的全文阅读卡片。全文源文件被替换或删除后，这些旧卡片不会继续出现在新报告里。

此外提供推荐质量评价工具：一键导出论文人工标注 CSV，填写0–3级相关性后可离线计算 P@10、标注集内 Recall@10、NDCG@10、MRR 和覆盖率。

## 安装与升级

新增长期维护依赖 `pypdf>=5,<7`。Windows 用户建议先备份原目录，特别是 `settings.json`、`data/`、`downloads/`、`reports/`，再将新程序文件合并进旧目录。参阅 `docs/UPDATING.md`。

## 安全与已知限制

索引仅读取本机受控下载文件夹中的 PDF，不自动突破期刊授权。扫描版和复杂公式/表格可能无法提取；AI 卡片只覆盖部分文本片段，学术解释仍需研究者核对。默认不向模型发送全文。基础检索与报告无需模型 Key。

自动检查更新功能保留，但必须先在仓库正式发布对应 GitHub Release，旧客户端才能看到更新提醒。
