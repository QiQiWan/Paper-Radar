# Paper-Radar v1.14.0 测试与验证记录

测试日期：2026-11-04。版本基线：v1.13.1。范围：本地实验 Agent 工作流和原有系统回归。

## 已验证

1. **全套 Python 回归：199/199 通过**（v1.13.1 基线 191，新增 8 项科研分析测试；后者部分包含多个独立断言与模拟场景）。命令：`python -m pytest -q`。
2. **研究 Agent 注册和故障边界：** 四个新 Agent 的顺序、依赖、受控输出与资源声明；`python -m paper_radar.agents doctor` 检查所有13个工作流 Agent。
3. **科研证据：** 正确引文可入库；伪造数字、基线、数据集、指标和不匹配页码/原文均被拒绝；重复候选去重；格式错误不覆盖原有证据。
4. **PDF 变更保护：** 分析期间修改 PDF 会拒绝保存；文件替换后旧实验证据不再被状态查询和导出使用；重新解析须再次调用模型。
5. **模型调用与缓存：** 不提供真实云端 Key 的模拟模型返回测试；相同 PDF+模型+提示词版本命中缓存，模型变更后重新处理。
6. **HTTP：** 使用 `ThreadingHTTPServer` 真实本地请求，检查实验分析状态、论文不存在的 404、POST CSRF Token 拦截及请求参数校验。
7. **数据导出：** 模拟两个研究主题，验证导出范围、PDF 有效性及 CSV 公式注入防护。
8. **前端浏览器：** 使用 Chromium 运行实际 HTML/CSS/JS 并模拟后端响应，1400px 桌面和 390px 手机均可显示实验卡片及独立科研 Agent 链；无横向溢出、JavaScript 页面错误。截图属于*离线界面验证*，不是生产环境或真实云端执行结果。
9. **静态检查：** `python -m compileall -q main.py paper_radar` 和 `node --check paper_radar/static/app.js`。
