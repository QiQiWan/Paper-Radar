## v1.22.0 专项功能覆盖

- 20 页程序生成的真实 PDF 文件经过隔离 PDF Worker 解析，原先前八页之外的第 13/19 页实验内容可进入 12 页候选页集合。
- 单篇最多三批模型调用，每批最多四个实验候选页；每个账号模型调用独立计数，命中可信完整缓存时不重复调用。
- 第二批故障后，任务显示部分完成；通过的批次和既有已核验证据不丢失；未完成的提取结果不写入完整缓存；重新分析可完成三批。
- 模型调用额度耗尽时明确显示，未授权云分析时没有网络模型调用；即使第三方模型 SDK 异常，也不抹除旧索引。
- 原文引文跨换行和空格的正常化与读回一致；不同物理 PDF、模型输出造假、伪造页码均需通过来源 SHA/原文逐字匹配。
- 合成的跨论文同字段候选仍被标记为需要人工复核，基线与单位表达冲突分别计数；异实验条件不自动归组。
- 网页、任务详情和历史报告使用已完成的服务端结果；代码未使用跨论文模型猜测的排名或因果结论。

## 真实论文种子集的实测结果与边界

本版本运行 `tools/eval_real_papers.py score`，结果如下：

| 指标 | 实际输出 | 解释 |
| --- | --- | --- |
| 真实论文元数据 | 3 篇 | Fourier Neural Operator、U-FNO、PINO |
| 人工复核种子证据 | 6 条 | 固定物理页和表格短引文 |
| 已标注不可比配对 | 5 组 | 5/5 被阻断，全部为负例 |
| 已标注可比配对 | 0 组 | 无法测量真实跨论文可比召回率 |
| 本地成功解析的原始论文 PDF | 0/3 | 三份原始 PDF 未包含在源码包中，且未实际下载 |
| 真实 PDF 页码锚点召回率 | `null` | 未测量，不能记为 0% 或 100% |
| 真实 PDF 候选页召回率 | `null` | 未测量 |
| 真实 PDF 候选片段锚点覆盖率 | `null` | 未测量 |
| 真实模型实验数值 Precision/Recall/F1 | 未测量 | 没有提交真实模型推理预测文件 |

5/5 仅表示在很小的、全为不可比标签的人工标注集上，没有形成违规候选。**绝不代表跨论文可比性识别准确率达到 100%。** 合成 20 页 PDF 的测试验证了数据通路和断言行为，不能用于估计真实科研论文的抽取性能。

## 未完成的现场验收

- 真正的公网 HTTPS/Nginx 上传、超过十万次请求的负载测试、高并发 SQLite 写锁压力及跨机存储场景；
- Windows 目标机自动更新（含生产 Ed25519 发布签名）、任务子进程终止以及服务恢复；CI 中已配置 Windows 冒烟作业，但当前容器不能声称 Windows 实机通过；
- 真实云模型服务的不同厂商兼容性、费用、限流、接口超时与科研抽取精度；
- 真实 PDF 两栏排版/扫描/OCR/跨页表格、含大附录的论文以及 12 MiB/40 页限制的有效覆盖；
- 基于真实论文且含“可比”正例的人工双人标注基准的统计质量。

因此本版本可作为**离线功能回归通过的受控迭代源码**。面向实际公网用户的生产验收仍需在目标环境按 `docs/UPGRADING_V1.22.0.md` 完成。
