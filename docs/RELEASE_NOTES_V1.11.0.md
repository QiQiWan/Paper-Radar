# Paper-Radar v1.11.0 发布说明

本次升级聚焦研究主题之间的数据隔离与可解释的论文推荐，并保留 v1.10.0 的自动检查 GitHub 更新功能。

主要新增能力：各课题独立的相关性反馈、星标、阅读状态和推荐证据；可选的标题摘要 AI 重排序、OpenAlex 语义发现；全主题依次检索、Windows 每日全主题检索开关；本地持久化运行历史。更新日志、架构、接口与操作手册已同步。

**默认保持低成本：** AI 重排序和语义来源均为可选、默认关闭。没有 API Key 仍可使用普通检索、PDF 与报告。推荐证据只来自标题和摘要，无法证明论文全文结论。

**升级方法：** 完整备份原目录中 `settings.json`、`data/`、`downloads/` 和 `reports/` 后，将新版程序文件覆盖到旧目录，保留用户数据。旧论文统一归属默认主题；此前建立的其他主题需重新检索，以恢复精确的论文归属。详见 `docs/UPDATING.md`。

**验证情况：** 原有与新增自动测试合计 143 项通过；HTTP 健康接口、Python 编译、JavaScript 语法与桌面/移动端离线布局检查通过。未对真实付费 API、Windows 计划任务和 Zotero 实机进行端到端验收。

**发布要求：** 仓库中的程序和文档须使用一致的 `1.11.0` 版本号，发布公开、非预发布的 GitHub Release，用户客户端才能发现此版本。程序只提示官方链接，不自动升级本地源文件。
