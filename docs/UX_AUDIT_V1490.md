# Paper-Radar v1.49.0 模型配置与研究阅读体验审阅

## 总体结论

v1.49.0 将模型配置从技术设置表单提取为三步向导，把自动跟踪和来源查询预算移到独立向导与设置，并在 PDF 阅读中提供摘要、实验候选和可按页码核查的问答。在没有模型密钥时，公开检索及本地原文定位仍可用。默认启用模型辅助不会绕过研究数据传输授权或收费测试确认。

## 科研结果的使用边界

1. PDF 原文定位可以证明“该页出现某一文本”，尚不能保证模型完整理解论文内容。
2. 阅读摘要与实验候选未经人工确认时，必须与已确认结论分开呈现。跨论文比较仍需确认指标、数据集、实验条件一致。
3. 本地模型回答要求给出合法引用编号，并禁止出现对应原文片段不存在的数量；没有证据时只返回原文检索情况。启发式语言匹配无法覆盖所有中文术语，仍可提示用户改用原文英文关键词。
4. 公网用户只可访问当前账号和研究主题允许的论文；文件指纹变化后不再引用旧版 PDF 的索引。

## 发现并处理的细节

- 旧版一屏展示服务商、接口地址、模型名称、API 密钥、数据传输授权与用量估算，用户很难判断操作顺序；新版只暴露当前步骤，专业参数按需展开。
- 本地版与公网版模型密钥的管理主体不同；新版明确由谁配置密钥，避免普通用户尝试在公网填个人 Key。
- 检索页中包含自动任务与查询预算等低频操作，首屏信息冗余；新版抽离，主检索仍提供直接关键词编辑和来源选择。
- 中文问题直接对英文 PDF 做字面匹配时很难命中；新版提供少量标准学术词汇对应的英文检索候选，保持可解释且不引入模型费用。
- 自动跟踪是否成功必须以后台任务实际安装状态为依据，不能仅以配置已保存判定成功；Windows 以外提示使用系统计划任务。

## 完整回归与自动化审阅结果

- **864 项仓库回归测试全部通过**，分为 432 + 432 两个独立批次执行；两批退出码均为 0。第一次环境变量覆盖临时测试目录的失败在隔离后消失。
- **20/20 项浏览器操作联动通过**，覆盖本地及公网模型引导、权限、自动跟踪和 PDF 阅读；**20/20 项布局检查无横向溢出**。
- 独立真人试用计时工具已验证可导出匿名 CSV，并增加 CSV 公式字符转义。真实用户数据尚未取得。
- 详细测试边界与方法见 [v1.49.0 测试结果](TEST_RESULTS_V1490.md)。
