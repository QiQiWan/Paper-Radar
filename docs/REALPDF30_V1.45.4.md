# Paper-Radar v1.45.4 | 科研证据完整性与长篇 PDF 工作流验收

版本：v1.45.4 研发验证版。基线：v1.45.3。日期：2026-11-10。

## 一、审阅结论

现有的 SynthesisAgent 已能连接论文检索、PDF 索引、人工确认结论、科研分析与长期研究记忆，但在结论归属、证据状态跟踪、长文档摘录与结果差异判断上仍存在可明确复现的代码缺陷。修复这些基础问题比立即增加多轮大模型 Agent 更有实际收益。

本轮未调用任何外部模型 API，也没有将历史 14 题开发样本冒充独立盲测或双人标注结果。**30 篇论文评估集的双人正式金标准仍为 0，暂不能计算正式模型 F1。**

## 二、本轮已实际修复的问题

| 问题 | 根因 | 修复方案 | 验收依据 |
|---|---|---|---|
| 240 页 PDF 后半部分无法保存原文证据 | 解析器升级到 240 页后，证据链接口、浏览器和 SQLite 约束仍停留在 120 页 | 同步页面范围；追加本地研究库 v8、公网工作区 v15 迁移；事务内保留证据与关联 | 固定版本《The AI Scientist》185 页文档，第 167 页本地和公网摘录成功 |
| 跨论文方法错误归属 | 使用一条综合结论的全文词汇并集，向其引用的全部论文分派方法名 | 每条证据根据**本篇原文摘录及标题**计算方法候选；保留“方法角色未确认”状态 | 单条结论引用 FNO 与 PINO 两篇论文的负例测试 |
| 历史综合报告失效检测不完整 | 指纹未覆盖审核过的实验 value、setting、review_decision 等字段 | 指纹 v2，加入结论状态、锚点、原文哈希和完整实验复核字段 | 修改数值、审核决定或 PDF 哈希后，指纹变化 |
| 长期记忆来源变更未完全感知 | 确认型记忆只锁定正文与修订号 | 锁定具体来源、实验审核字段与关联锚点 | 实验值与 PDF 指纹变更时不复用旧记忆 |
| 模型用两份真实证据交叉拼装错误实验值 | 校验只要求数字出现在任意被引用结论里 | 对含方法和数字的子句要求**同一来源锚点**支持该方法与数值；限制可引用的 ID 为实际发送给模型的 12 条以内 | “FNO 错引用 PINO 数值”被拒绝，原始正确数值保留 |
| 微小格式差异被判作结果分歧 | 数值字符串直接按文本去重 | 用 Decimal 比较纯数字；百分号/单位不一致另列为待复核项；非标准统计格式不自动比较 | 0.30/0.3 不产生差异；0.3/0.5 候选；0.3/0.5% 单位错配 |
| 否定词处理可能误判 | 正向动词被包含在否定表达中 | 优先解析显式否定，仍然只输出冲突候选 | “did not significantly improve”负例 |

**指纹 v2 兼容性说明：**过往未记录 v2 指纹的历史综合报告/周期简报会以“需复核”展示；它们的不可修改历史正文仍被保留。旧版长期记忆引用会在首次检查时要求复核。这样可避免遗漏旧版本保存时未覆盖的审核信息。

**数据库迁移说明：**增量迁移仅适用于从低版本向高版本升级。它会在 SQLite 事务中重建 `research_anchors` 表的页码约束，并恢复 `research_claim_links` 中的全部外键关系。迁移不修改 `research_claim_audit`、`research_memory_audit` 或既有报告快照；生产环境升级前仍应创建完整数据库备份。

## 三、185 页真实 PDF 验收

- PDF：arXiv `2408.06292v1`（《The AI Scientist》），已使用原始 PDF 字节而非重新生成的测试副本。
- 输入 SHA-256：`670300c77b3a043b90c24223e96bcb664f2019073364eb6e7e7b633635ad0765`。
- 本地：解析 185/185 页；第 167 页保存原文摘录成功；本次约 2.23 秒（本容器测试）。
- 公网工作区：解析 185/185 页；第 167 页完成 PDF 文本预览及摘录入库；本次约 25.66 秒（本容器测试）。
- 上述两个流程均未调用模型。第 167 页的原文是检验操作正确性的样本，**不能证明模型已理解该页面的学术含义**。
- 上述耗时仅适用于当前容器和该 PDF，不能作为 Windows/macOS 真实机器上的性能保证。

在完整源码目录中运行：

```bash
python -m tools.v1454_realpdf_provenance_smoke \
  --pdf /path/to/2408.06292v1.pdf \
  --expected-sha256 670300c77b3a043b90c24223e96bcb664f2019073364eb6e7e7b633635ad0765 \
  --page 167 --output realpdf_167.json
```

此命令将 PDF 临时复制到受控数据目录，执行本地索引和证据写入，并在结束时清理临时文件。不会连接网络、调用模型或改动用户的正式论文数据库。可通过 `RUN_SCIENCE_AUDIT_V1454_WINDOWS.bat` 或同名 Mac/Linux 脚本执行无需 PDF 的专项回归。

## 四、当前不能认定完成的任务

1. **人工正式金标准：**30 篇 PDF、117 条证据候选、139 道问题与 34 组论文配对，尚未完成两名独立研究者的盲审和仲裁。当前已有单轮 PDF 表格核查例子不能替代双人金标准。
2. **真实模型回答质量：**未对 256 项统一模型任务执行带预算的实时 API 调用，不能报告问答正确率、综述事实支持率或冲突判断 F1。
3. **指标关系验证：**同一段原文同时出现方法与数字，仍可能需要检查具体表格单元格归属。当前新模型校验是高风险拼接的检测器，不等价于语义上完全证明数值因果关系。
4. **跨平台发行：**当前版本为研发集成源码，尚未由 GitHub Windows/Ubuntu/macOS Intel/ARM Runner 完成正式原生安装包验收。
