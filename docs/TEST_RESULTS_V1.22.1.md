## 3. 测试中发现并处理的兼容冲突

首次完整回归 384 项中 383 项通过，1 项失败。失败源于历史测试要求“代理头无效则默认使用 127.0.0.1”，与本版主动设计的**拒绝无效代理头**安全策略冲突。修正旧测试的预期并增加自动更新防误覆盖专项测试后，最终全部 389 项回归通过。旧行为已经在代码中实际删除，属于有意识的兼容行为变化。

## 4. 测试边界与尚未解决的问题

1. 当前环境通过 Playwright/Chromium 尝试访问本地 HTTP 服务时返回浏览器环境策略错误 `ERR_BLOCKED_BY_ADMINISTRATOR`。因此未完成真实浏览器中的断线重连交互测试，不能以 JS 静态测试代替该项验收。
2. 临时 Nginx 使用自签证书和隔离端口；**未验证**正式域名、证书续期、生产服务器中的真实 systemd 用户/路径权限、边界防火墙或 CDN/二级反向代理客户端 IP 链。
3. 未进行 Windows 实机运行/自动更新、生产 Ed25519 签名发布、真实论文站点故障注入和高并发长稳压测。
4. 文本级实验归属检查只拦截明显错误，不具备二维表格坐标、跨栏、OCR、实验条件等全面关系核验能力。当前只有 3 篇真实论文种子基准；不能宣称已实现科学准确率验收。
5. 已知 `12 MiB` PDF 限额、解析页数与文献质量基准不足等问题仍保留到后续结构化文献解析版本；本热修复不改动上传配额的业务边界。
6. API 用量 JSON 是聚合观测文件，不具备正式计费级日志审计、永不丢失保证或全量事件溯源；多 Worker 并发覆盖问题本次已修复。

## 5. 生产部署准入条件

进入正式生产前必须完成：停机备份并演练 v5 回滚、在目标 Linux 上执行 `nginx -t` 和 systemd 启动、从两个公网地址验收 IP 独立限流、真实浏览器掉线重连、生产 HTTPS/证书和 Worker 租约恢复，以及基本多用户并发观察。建议优先执行 [v1.22.1 升级手册](UPGRADING_V1.22.1.md) 中的验收表。
