## 自动化环境限制

此环境的 Chromium 对普通 HTTP、本地文件及 data: 地址导航返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。页面交互测试因此采用 `page.set_content` 挂载**真实的批量审核组件和 CSS**，并由 Python 桥接访问隔离启动的真实 HTTP 接口及 SQLite 数据库。已验证组件行为、状态更新和响应；未完成从本机 URL 地址栏打开整站的原生 E2E 验收。

在线 arXiv 等来源和真实付费模型 API 没有在此环境运行，也未接触使用者的现有 60 篇论文及其本机数据。下载成功率、模型实验字段准确率、PDF 表格还原效果和人工核对平均时长均须通过用户电脑上的真实论文试点测量。

## 安全与科研证据检查

- 不授权模型时不会发送 PDF 到外部服务；选择模型时仍需明确授权。
- 审核具有乐观锁版本号；只有逐字存在于当前 PDF 页的数值及实验字段可以被确认。
- PDF 指纹变化后旧确认失效；旧引文不会参与对照。
- 人工撤销不保留可继续复用的孤立锚点；如已被研究结论引用，要求先解除关联。
- CSV 采用 UTF-8 BOM 和基本公式注入防护；诊断 ZIP 不包含论文全文和密钥。
- 跨论文数值列表只作并列展示，自动结论和优劣排序继续禁止。
