# Paper-Radar v1.13.1 发布说明

**日期：2026-11-04｜基于 v1.13.0 的安全增量迭代。**

- Agent 注册契约增加能力声明、最大执行次数、退避间隔、协作式时间预算。
- Discovery 可对可判定的暂时性网络故障再尝试一次；写库、下载、报告和可能计费的云端模型阶段禁止自动重试。
- Agent 运行记录新增重试次数、超出预算标记、按阶段的本地 Token 使用和可选费用估算。
- 设置页新增手动输入模型单价，并在 Agent 视图展示相应诊断。
- 增加离线 `python -m paper_radar.agents doctor`、故障注入测试和运行时契约回归。
- 既有检索、Zotero、全文证据、定时任务、Word/Markdown 报告和更新提醒继续保留。

**注意：** 时间预算采用协作式检查；网络函数仍依靠自身超时，不提供随时强制终止。模型费用按用户设置单价估算，与正式账单可能不同。旧版数据库和配置可继续使用，无需手动迁移。

详见 [运行治理设计](AGENT_RUNTIME_V1.13.1.md)、[升级指南](UPDATING.md)、[更新日志](../CHANGELOG.md)。
