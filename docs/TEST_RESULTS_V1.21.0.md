# Paper-Radar v1.21.0 测试结果与验收边界

验收日期：2026-11-05。基线为 v1.20.0。此报告仅记录在当前运行环境已实际执行的代码测试；未假设 Windows、公网、机构授权或真实第三方服务可访问。

## 一、测试范围与方法

- **完整测试集（开发目录）**：分组运行 `PYTHONPATH=. python -m pytest -q` 对应的全部 31 个测试文件，以避免长时间单进程运行期间的环境超时。A 组 74 项、B 组 152 项、C1 组 25 项、C2 组 101 项；**合计 352/352 项通过**。
- **新增专项验证**：持续阻塞来源的绝对超时与进程回收、取消传播、Agent 执行截止、健康来源继续运行、全部来源失败记录及诊断、来源子进程正常响应、账号隔离的 PDF 预览、HTTP 字节范围与 416、SHA-256 失效、Synthesis 基线冲突、HTML/JS 双栏与矩阵契约、失败进度收敛及移动端布局约束。
- **真实 HTTP 服务端测试**：使用服务进程和 HTTP 客户端，验证注册后的访问控制、跨账号拒绝、PDF 的 200/206、范围错误的 416 和 PDF 替换后的 404。
- **浏览器端测试**：系统 Chromium + Playwright，真实公网 HTML/CSS/JavaScript 通过 Python 的 HTTP 桥接访问真实本地后端，以合成 PDF 和两条实验记录检验双栏展示和报告矩阵。系统限制浏览器直接打开本地服务，测试时浏览器内置 PDF 的文档源替换为合成 PDF 数据 URL；**因此没有声称真实公网原生 PDF 插件已经验收**。

## 二、可复现的功能结论

| 场景 | 测试方式 | 结果 |
| --- | --- | --- |
| 文献来源一直不响应 | 子进程 sleep，0.35 秒预算 | 超时并终止进程，通过 |
| 用户取消来源查询 | 协作检查点抛中断 | 父任务获知取消，来源进程回收，通过 |
| Agent 取消/超时 | 注入 `AgentCancelled` 和 `AgentDeadlineExceeded` | 不作为普通来源错误吞掉，通过 |
| 一个来源不可用、另一个健康 | 注入超时/论文结果 | 继续健康来源，保留超时诊断，通过 |
| 所有来源失败 | 所有适配器注入超时 | 抛出可读错误；Web 记录失败、诊断和 100% 完成状态，通过 |
| 公网未登录读取 PDF | 真实 HTTP GET | 401，通过 |
| 跨账号读取 PDF | 两个独立账号 | 拒绝访问，通过 |
| 有效账号读取 PDF | 当前用户的有效 PDF | HTTP 200、内容一致、无缓存、SAMEORIGIN，通过 |
| PDF 字节范围和非法范围 | HTTP Range | 正常 206 / 非法 416，通过 |
| 用户在外部替换 PDF | SHA-256 验证 | 禁止读取旧版证据，404，通过 |
| 实验基线冲突 | 两篇合成测试记录 | 矩阵保留原数值并警告“基线不一致”，通过 |
| 桌面、手机 UI | Playwright 1440px / 390px | 矩阵 1 组、2 行，PDF 两栏 DOM、证据卡片；无 JS page error、无页面横向溢出，通过 |
| 移动端宽表 | 390px 矩阵报告 | 先发现横向撑宽，修改 grid 最小列宽与局部滚动后复测通过 |

## 三、未完成的真实环境验收

1. **真实不可达文献站点**（校园网/VPN、超时、Springer/Elsevier 授权）在 Windows 或服务器上的完整请求耗时及不同来源组合，尚未联网验收。本轮网络故障测试由独立故障注入与受控子进程完成。
2. **原生 PDF 嵌入阅读**：Chromium 当前环境限制直接访问 localhost 并阻拦对 HTML 伪域名的导航；通过真实 HTTP 请求和界面布局桥接分别验收，不能据此保证 Chrome/Edge/Safari 在生产 HTTPS 下的 PDF 插件完全一致。遇不支持的插件，界面保留新标签页打开入口。
3. **复杂 PDF 表格/公式识别、OCR 召回和真实科研数据**未在本轮扩展。真实论文种子基准继承 v1.19，没有新增模型准确率成绩。
4. **Windows 计划任务、Ed25519 生产密钥签署、正式 GitHub Release 自动安装和 Nginx/TLS**未在本环境验收。
5. 当前 Web/Worker 单主机 SQLite 部署和任务资源配额延续旧版限制，尚不能据此推断公有云高并发可靠性。

## 四、重现实验

```bash
python -m pytest -q
python -m paper_radar.agents doctor
python -m compileall -q paper_radar tests
node --check paper_radar/static/app.js
node --check paper_radar/static/portal.js
```

完整版单命令测试适用于稳定的本地终端；当前沙箱曾在单命令等待期间触发运行超时，最终结果由四组互不重叠的测试文件全部覆盖。正式发版前建议在 Windows/Linux CI 上各执行一次，并记录测试时间、操作系统和依赖锁定版本。
