# Paper-Radar v1.21.0 操作手册：断网恢复、原文精读、实验比较

## 一、文献检索网站无法访问时如何处理

**症状**：检索进度停在某个来源或某组关键词，页面长时间没有变化。

新版先完成来源发现，再继续筛选、入库与报告。生产检索中的每个来源网络请求由独立子进程执行，默认每组最长 10 秒，来源发现总预算 75 秒。当前请求等待时显示剩余秒数；超时后跳过该来源的其余关键词组并继续其他来源。

操作步骤：

1. 桌面版选择研究主题，进入“设置 → 来源故障与超时控制”。一般先保持 10/75 秒的默认值；网络常年不可访问的来源可取消勾选。
2. 返回“工作台”，启动一次普通检索。观察“任务进度”及当前来源、关键词组和剩余时间提示。
3. 任务结束后，展开“查看各文献来源的连接结果”。“正常完成”“部分可用”“连接超时已跳过”分别对应不同状态。
4. 如果所有来源均失败，会明确显示失败和错误信息；此前论文、已下载 PDF 及已保存报告不受影响。可以继续离线阅读，网络恢复后再重试。
5. 如果确实需要 Springer/Elsevier 题录，请先确认 API Key、机构订阅、校园网/VPN 权限；未授权的来源建议关闭。

**注意**：来源发现阶段的时间预算不包含后续 AI 摘要、PDF 下载、全文分析和导出耗时。公网账号版的 arXiv 请求另有全局节流，不能通过增加 Worker 绕过来源请求频率。

## 二、PDF 与证据双栏精读

桌面版：进入“论文库”，选择已保存 PDF 的论文，点击“全文证据”。左侧显示 PDF，右侧显示 AI 阅读卡片和实验指标。点击引文上的“第 X 页”可定位同一个 PDF 的对应页。

公网版：登录自己的账号，选择研究主题 → “论文库” → 选择论文 → “查看证据”。具有有效 PDF 时显示 PDF 原文与证据两栏；在页码框输入页码并点击“跳转”，右侧同时刷新该页的已核验指标、原文引用和可展开的提取文字。手机使用上下排列。

PDF 尚未获取：先点击“上传 PDF”，上传本人有权使用的 PDF；或者运行受控研究任务尝试合法的开放版本。上传 PDF 后根据页面提示运行“分析 PDF”，从而获得逐页索引。公网端限单 PDF 12 MiB、最多 30 个文件/账号及总 180 MiB 左右空间；具体以服务端配置和限制为准。

**数据核验**：PDF 被替换后，旧的 SHA-256 证据不再有效。若论文存在表格合并单元格、图像扫描或跨页公式，请始终打开原文人工核对。浏览器无法内嵌 PDF 时可使用“在单独标签打开 PDF”。

## 三、查看跨论文实验比较矩阵

1. 登录公网工作台，切换到对应研究主题。
2. 进入“研究报告”，点击一份已有的研究快照旁的“在线阅读”。如尚无报告，先从“任务中心”完成科研分析，或在报告页启动跨论文比较任务，由独立 Worker 生成快照。
3. 页面将报告中的相同数据集/指标/实验条件候选组织成矩阵；输入数据集或指标关键词可以缩小范围。
4. 逐行查看**论文标题、原文数值、对照基线和证据等级**。“本地 PDF 已核验”表示服务器已检查对应 PDF 版本和引文；“待复核”表示来源可能是导入 CSV。
5. 点击某行的“核查第 X 页”进入论文库中的 PDF 原文及证据界面。如报告是在旧版本 PDF 上生成的快照，还需检查当前 PDF 的版本是否变化。
6. 看到“对照基线不一致”“单位表达不同”“缺少实验条件”等风险提示时，只能作为研究线索。正式使用数值前应人工核对任务、数据划分、单位、评价口径、随机种子和基线实现。

**报告声明**：该矩阵不会自动计算跨论文性能提升，不为不同实验设置的模型排序。已有历史 Markdown 快照仍可在原报告阅读区和下载入口获取。
