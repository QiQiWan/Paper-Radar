# Paper-Radar v1.28.0 发布说明

## 重点改进

此次版本统一了 Bash 启动、桌面运行管理与浏览器配置的进程控制方式。首次启动会展示简短引导；工作台与公网门户加入内置教程入口。源码运行版可经用户确认，等待任务完成、安全关闭当前用户服务，再执行有发布校验和回滚保护的更新。

## 操作步骤

1. 终端启动：运行 `./start_macos_linux.sh`。默认前台，按 `Ctrl+C` 干净退出（不再输出 Python 异常栈）；使用 `--background` 本次后台运行。
2. 在网页“设置 → 软件更新与运行”选择下一次运行的默认模式并保存。切换运行模式需要下次启动生效。
3. 首次启动出现三步引导，关闭后可继续使用；左侧“使用教程”可随时再次查看操作流程。
4. 软件检测到新的公开正式 Release 后，先查看版本说明，再点击“确认并安装”，并在弹窗中确认。升级期间服务会暂时离线，升级辅助进程将等待当前任务完成、停止当前用户的本地实例、校验发布文件并安装；成功后自动重启。
5. 更新结果可查看 `.paper_radar_updates/handoff_status.json` 和 `.paper_radar_updates/handoff.log`。

## 安全与兼容性说明

- 现有用户数据、论文数据库与历史报告结构不变。本次没有新增数据库迁移。
- 安装版 EXE/APP 必须由各平台原生安装器升级；公网 systemd Web/Worker 必须在管理员维护窗口升级，网页不会自动停止生产服务。
- 不会终止他人会话或强制杀死正在执行的科研任务，最多等待约 5 分钟后退出并提示失败。
- 手动源码更新要求受信仓库的最新公开正式 Release，附件须通过既有完整性和发布签名校验。**GitHub Prerelease 不会触发这项源码安装**。
- 本轮已完成源码模式自动化和本地 HTTP 验证；Windows、macOS 原生构建、实际 GitHub 升级与正式公网服务器仍需目标环境验收。
