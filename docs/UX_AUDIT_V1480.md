## 审阅结论

本轮主要降低了普通科研人员首次使用模型及完成文献检索的门槛。新安装默认选择模型辅助；界面能明确区分“已经选中 AI”和“模型已连接”，也区分模型配置、数据传输授权和具体任务确认。常规检索与本地证据整理在没有密钥时继续运行。现有高级科学证据工具、报告归档和后台任务接口保留。

## 当前使用方式

本地版：启动程序 → 首页或找论文 → 若出现“AI 功能已开启，尚未添加模型密钥”，点击“添加模型密钥” → 选择服务商、填写 API Key → 阅读发送范围说明并按需授权 → 保存模型设置 → 返回找论文。新用户没有密钥也可直接输入关键词并检索。

公网版：登录后 AI 分析复选框默认开启。若服务器没有预设模型服务，点击“查看连接方法”打开设置说明；普通用户联系管理员，管理员按说明配置服务器私有环境变量。执行分析时可选择“继续普通 PDF 解析”，无需等待模型开通。

## 风险和权限边界

1. “默认开启”只决定操作偏好；没有 API Key 和必要授权，任何前端默认选中状态都不能绕过服务端拦截。
2. 本地研究分析采用个人密钥，公网版采用服务器统一密钥，二者的连接方法不同。公网仍未提供每位账号用户单独配置 BYOK 的能力。
3. 当前没有真实外网环境下的模型调用测试和收费准确性校验，API 可用性及费用应在正式发布前分别确认。
4. 浏览器 QA 采用真实页面 + 真实本地 HTTP/SQLite，通过请求桥接实现；无法验证系统浏览器真实导航、Cookie 策略和文件下载链路。
5. 不具备可量化的普通用户易用性研究数据；降低学习成本的判断来自 UI 审阅和操作步骤减少，尚未开展五人以上的独立用户测试。

## 后续仍需优化

### P0：先做实际用户验收

- 在 Windows/macOS 下测试真实双击启动与浏览器自动打开，分别验证有密钥/无密钥/密钥错误/额度不足/模型限流。
- 使用至少五名未参与开发的科研人员完成“研究主题—检索—阅读 PDF—研究分析—导出报告”，记录任务成功率、完成时间、理解障碍和人工求助次数。
- 验证 arXiv、OpenAlex、Crossref、OpenReview 实际网络环境的服务返回和来源失败分流。

### P1：继续减少重复入口和专业参数

- 将本地运行记录与公网任务详情进一步压缩为状态摘要和故障展开两层，减少任务 ID 与运行参数对普通用户的干扰。
- 统一 PDF 上传、下载、已有全文与无权限全文的操作提示；优化全文无法读取时的建议路径。
- 将长期定期跟踪的配置从普通检索表单抽离，提供独立易懂的“每周/每日更新”向导。
- 在不降低研究可追溯性的前提下，完善研究报告的结构化对比和实验依据定位；无人工确认材料时明确报告范围。

### P2：正式版本管理与易部署性

- 进一步整合散落 CSS/JS 样式覆盖，统一设计令牌与语义化表单组件；建立稳定的截图回归基线。
- 为公网部署提供管理员密钥轮换、连接诊断和审计方案，同时维持凭据不可回显与最小权限。
- 真实双人标注与仲裁完结后再测量科学分析质量，避免用组件测试通过率替代研究准确率。
