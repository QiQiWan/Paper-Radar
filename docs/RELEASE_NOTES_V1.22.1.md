# Paper-Radar v1.22.1 发布说明（可靠性热修复）

发布日期：2026-11-05。基线：v1.22.0。包含 v1.21.1—v1.22.0 的全部已有功能。

## 结论

v1.22.1 修正了原部署模板的只读安装路径写入冲突、公网反向代理登录限流共用地址、已收录论文题录不更新和任务轮询掉线无法恢复等问题；同时加固了科研实验归属的保守检查、云模型用量持久化和内部故障追踪。

本版改变了**公网用户工作区数据库结构**：`portal_workspace` 从 v4 追加迁移到 v5。升级前必须停止 Web 和所有 Worker 并备份数据库与 PDF。**旧版 v1.22.0 无法直接读取升级后的 v5 工作区数据库，回滚程序时需要同时恢复升级前备份。**账号数据库 `portal_auth` 的迁移版本保持不变。

## 已完成的修复

| 范围 | 改动 | 用户可观察的行为 |
| --- | --- | --- |
| 只读部署 | 公开服务运行标记放到 `<data-root>/runtime/`，不再写入只读源码目录 | `ProtectSystem=strict` 的安装不因运行标记写入失败而退出；旧源码目录的遗留标记不妨碍启动 |
| 公网 IP | systemd 显式开启可信代理 IP，Nginx 两条反向代理规则覆盖 `X-Real-IP`；缺少有效地址时拒绝操作 | 不同公网 IP 的登录速率配额独立，不再合并到 `127.0.0.1` |
| 注册安全 | 生产服务模板默认 `--disable-registration`，增加终端 `user-create` 指令 | 网站隐藏注册页签；管理员可以通过终端创建普通用户，不把密码写在命令行 |
| 题录版本 | 使用 arXiv `updated` 时间更新题名、摘要、DOI 等；增量记录修订时间与标题变更 | 重检索可更新已有论文数据，不清空收藏、已读、相关性反馈；旧版不会覆盖新版 |
| 轮询恢复 | 前端失败后指数退避并加随机抖动，网络恢复和标签页重新激活后主动刷新 | 一次临时网络故障后可自动继续更新后台任务，不重复提交科研任务 |
| 科研证据 | 拦截具有明确跨行错配特征的数值归属；读取旧证据时再次检查；统一标注行列关系待复核 | 明显错配的 `数据集—数值` 行不进入可信分析；文本引文匹配仍需人工核对表格 |
| 用量记录 | 云模型提供商用量账本迁至 `<data-root>/metrics/`，增加跨进程文件锁和原子写入 | 独立 Worker 并发调用不再因覆盖 JSON 导致计数丢失，支持只读代码安装 |
| 诊断日志 | HTTP 500 输出 `E_INTERNAL` 与 `request_id`，服务器审计同步记录编号，避免记录用户原文和令牌 | 可以用错误编号定位内部异常，同时限制日志泄露风险 |
| 运维诊断 | 新增 `tools/verify_public_deployment.py` | 可离线检查 Nginx/systemd 关键配置并对真实 Python HTTP 服务做回环冒烟 |
| 代码安全更新 | 桌面启动更新器同时识别旧标记、默认/环境变量数据目录新标记；Linux 还检查相同安装目录的服务进程 | 只读部署改造后仍能阻止公网服务运行期间被桌面更新器覆盖代码 |

## 功能与安全边界

- **可信代理**：仅在后端直接连接方为 loopback 且显式启用 `--trust-proxy-ip` 时信任 `X-Real-IP`。如果上游 Nginx 配置错误或没有传值，登录接口会拒绝请求并给出错误提示。绝不能直接在公网暴露后端端口。
- **注册策略变化**：发布的生产 systemd 模板默认关闭自助注册。已有用户仍可正常登录；如确需开放注册，应先配置反机器人、邮箱验证、流量保护和监控，并审查移除 `--disable-registration` 的风险。
- **题录更新**：只处理 arXiv 正式返回的元数据；没有源更新时间的结果不会覆盖已有、已知更晚的版本。题录版本记录不会重置个人阅读状态。
- **证据可信度**：`validate_experiments` 能排除部分明显的跨行拼接错误；不能从纯文本重建二维表格的行列关系。显示“引文已经匹配 PDF”不代表“实验数据关系全部校验通过”。
- **自动更新阻断**：新旧标记路径兼容；Linux 使用同安装目录的进程检测补充自定义数据目录。定制部署、Windows 实际自动更新和正式生产签名仍需实机验证；生产公网升级必须先停止 Web 与所有 Worker。
- **用量与限流**：供应商级 JSON 账本仍属于轻量监测手段；不构成计费系统。正式公网服务仍应使用模型提供方账单核对。

## 兼容与发布

- Python 3.10+；现有桌面版入口、已有 16 个 Agent、公网 PDF/报告功能保持兼容。
- 公网用户工作区发生 v4→v5 单向迁移；研究库、账号库不增加迁移。
- 源码 ZIP 为人工审核/手动部署产物，**没有生产 Ed25519 发布签名**，不能声称已经完成安全自动更新。
