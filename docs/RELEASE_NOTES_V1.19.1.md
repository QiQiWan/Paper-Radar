# Paper-Radar v1.19.1 发布说明

发布日期：2026-11-05。基线：v1.19.0。

**本版本聚焦公网工作台的操作闭环与可访问性。** 新增任务阶段事件、报告快照和只读在线阅读，完善任务失败提示、移动端表格及表单可访问标签；保留全部科研 Agent、Zotero、本地报告、独立 Worker 和账号权限。

数据库新增 `portal_auth` v6 和 `portal_workspace` v3 迁移。请停止公网 Web、Worker 进程，备份完整数据目录后升级。研究报告和任务历史按照当前账号隔离。

自动化测试：327 项全部通过；前端真实页面代码配模拟接口通过桌面和移动端浏览器检查；HTTP 接口在本地测试服务上完成身份及数据隔离验证。生产公网、高并发、Windows 自动更新及读屏器尚需目标环境验收。此交付源码尚未使用生产签名私钥签署，也未发布 GitHub 正式 Release。

本版本仍保留公网单页结构。五入口导航、独立任务中心、PDF 双栏精读和跨论文比较矩阵预计在后续 v1.20 系列开展。
