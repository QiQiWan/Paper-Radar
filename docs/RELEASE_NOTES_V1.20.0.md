# Paper-Radar v1.20.0 发布说明

## 本次用户可见变化

**公网工作台重构为五个入口：** 工作台、论文库、任务中心、研究报告、我的账号。手机端提供固定底部导航，桌面端使用左侧导航。工作台新增主题统计、最近任务及最近论文，任务与报告不再占用工作台同一长页面。

**公网论文库新增可保存的个人阅读管理：** 按题名、摘要、DOI 搜索；按星标、未读、在读、已读、相关反馈筛选；支持时间及题名排序、分页、星标、阅读状态和相关性反馈。所有标记按账号及研究主题隔离。

**桌面版补充“任务中心”：** 保留原有 Zotero、本地 PDF、模型设置与科研报告功能；扩展工具可从导航/设置进入。桌面任务中心显示已有运行状态和历史记录。

## 数据与兼容

- `portal_workspace` 新增迁移 v4：只追加 `topic_paper_flags`，保留原 `topic_papers`、文献、证据与报告表。
- 账号库仍为 v6；独立 Worker、Agent 数量及本地检索 API 保持兼容。
- 旧报告继续作为只读快照显示，打开历史报告不会重新触发模型。
- 升级前需停止 Web/Worker 并备份账号与全部用户工作区；旧客户端不能安全打开已升级数据库。

## 验证范围

自动化代码回归、独立 HTTP 账号/主题权限测试、旧数据库迁移保留检查、Python 与 JS 语法、Chromium 模拟数据下多视口 UI 和控件交互。真实 HTTPS、Windows 自动更新、生产模型、真实科研人员可用性和生产负载尚未验证。

v1.21 优先完善 PDF/证据双栏阅读、SynthesisAgent 实验比较矩阵、标准化错误码、前端独立业务组件与科研用户实测。
