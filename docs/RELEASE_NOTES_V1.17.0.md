# Paper-Radar v1.17.0 发布说明

v1.17.0 重点优化独立公网门户：SQLite 持久化 arXiv 检索任务、重启恢复、取消与历史查询；管理员查看队列状态；公网论文列表分页、真实 arXiv 请求的全局串行节流；修复 24 小时提交限额统计窗口；反向代理真实客户端 IP 可在可信 Nginx 下选择启用。

SynthesisAgent 增加证据重复、未核验来源、缺少实验条件、不同基线及单位不一致的诊断，并在 Markdown 比较报告保留逐条复核提示。仍坚持不自动计算跨论文领先百分比。

更新 `portal_auth` schema 至 v3，原账号及研究主题无需重新注册。部署前应停止公网服务并备份整个账号工作区。桌面版及 16 个 Agent 保持原有使用路径和 API 兼容。

公网版仍需可信 HTTPS 代理与严格运维安全策略；不包含邮箱验证、反机器人、完整的在线全文分析、强制终止阻塞 worker 或跨进程任务队列。Windows 自动更新的真实实机验收仍需在目标 Windows 系统进行。
