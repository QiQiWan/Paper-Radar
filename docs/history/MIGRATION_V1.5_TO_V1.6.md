# 从 v1.5 升级到 Paper-Radar v1.6

本次主要统一软件名称、GitHub 地址与启动标识。数据库结构及 `paper_radar` 模块名保持不变。

## 推荐升级步骤

1. 关闭旧版网页工作台，并确认没有正在执行的下载或检索任务。
2. 备份旧版目录中的 `settings.json`、`data/`、`reports/`、`downloads/` 和 `logs/`。这些目录可能包含个人研究信息，不要上传 GitHub。
3. 将 v1.6 解压到 `D:\Paper-Radar` 等固定目录。保留新目录中的源码和默认文件。
4. 将备份的用户配置、数据库、报告和下载文件拷贝到新目录对应位置。原目录无这些文件时无需拷贝。
5. 双击 `start_windows.bat`，打开 Paper-Radar，检查论文库数量和已下载文件。
6. 如曾安装旧版 Windows 后台任务，请在新版工作台重新点击“开启后台更新”。安装成功后，会清理旧任务 `LiteratureTracker_Daily`。新任务名为 `Paper-Radar_Daily`。
7. 检查“设置 → 中文速览”，确认原 API Key 能否自动读取。新版优先使用 `PAPER_RADAR_API_KEY` 环境变量，也兼容旧版名称。若原系统凭据不可用，可以重新输入一次。

## 使用过程中的注意事项

- 直接将文件夹移动到新位置，会使旧版任务中的绝对路径失效，所以务必重新安装后台任务。
- SQLite 数据库文件使用原格式；保存阅读状态和下载记录不会因为软件改名而重置。
- 如同时运行旧版和新版，浏览器端口可能不同。建议只保留一个在运行，避免对同一份数据库并发写入。
- 本次没有自动从旧目录移动私人数据。升级前请自行备份。

## 验证

```bash
python -m pytest -q
python main.py --cached
```

如果访问 `http://127.0.0.1:8765/api/health`，新版本应返回 `app` 为 `paper-radar`，版本为 `1.6.0`（端口按实际启动信息确定）。
