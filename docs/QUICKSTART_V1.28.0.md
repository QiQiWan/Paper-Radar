# Paper-Radar：五分钟快速入门

第一次启动会出现简短引导。关闭引导不会影响日后使用；在左侧“使用教程”可以随时重新打开本页。

## 1. 启动并确认运行状态

Windows、Ubuntu、macOS 安装版：双击 Paper-Radar，运行管理窗口会显示服务状态，并打开浏览器研究工作台。

使用源码的 Ubuntu/macOS 用户：执行 `./start_macos_linux.sh`。默认在终端前台运行，按 `Ctrl+C` 可以停止服务。若需要关闭终端后继续运行，请在“设置 → 软件更新与运行”选择后台运行并保存，下次启动生效；也可以使用 `./start_macos_linux.sh --background` 仅为这次选择后台模式。

网页“设置 → 运行诊断”可显示当前服务端口、进程号和停止入口。后台方式不影响科研任务；对正在运行的任务，系统会拒绝直接关闭。

## 2. 选研究主题，开始检索

打开“工作台”，选择研究主题，在“研究关键词”输入几个英文词组，用逗号分隔。点击“检索论文并更新报告”。首次使用无需配置 AI Key 或 Zotero。

检索出现连接失败时，可以在“任务中心”查看失败的文献来源；如果启用缓存，系统会标注过期结果。

## 3. 阅读文献

打开“论文库”，查看题名、摘要和原文链接。将感兴趣的文章标星，设为“阅读中”或“已读完”。对于可合法获取的开放 PDF，可使用下载与全文分析功能。

## 4. 获取研究报告

进入“研究报告”阅读结果并导出 Markdown 或 Word。涉及跨论文实验数字时，逐条核对 PDF 原始位置和实验设置；待复核证据不应作为确定性的比较结论。

## 5. 更新与退出

发现**公开正式版本**时，页面顶部会提供“确认并安装”。确认后本地服务将停止接收新任务，等待当前任务结束，再退出旧服务、执行完整性校验与备份，然后安装新版本并重启。安装过程中页面可能暂时断开连接，重启完成后刷新即可。

只有当前用户拥有的本机服务可以被自动关闭。生产公网服务、冻结安装版和无法安全结束的后台任务仍需要专门的更新步骤。更新失败会保留日志及回滚信息；详细操作请阅读“桌面运行与进程管理”。
