# Paper-Radar v1.49.2 功能修复及用户界面审查

版本：1.49.2｜2026-11-10｜状态：研发验证版

## 1. 总体判断

本轮出现的“检索词生成失败”和“研究分析没有实际内容”来自不同环节。日志中模型规划接口返回 HTTP 400，现有结构化结果校验只接受有限 JSON 格式；研究简报虽能成功保存，但主题中的 34 篇论文没有 PDF 原文锚点，也没有已人工核对的有效结论，加之中文提问不能有效召回英文题录，导致页面内容几乎为空。控制台两次 `BrokenPipeError` 发生在发送 HTTP 响应期间，之前被笼统归入数据库不可用，错误分类不准确。

本次修复保留原有人工证据验证规则，同时增加**题录候选、摘要片段、阅读顺序和待核对问题**，使证据不足时仍可开展文献阅读准备。经过人工确认的实验结论继续独立呈现。

## 3. 已落实的修改

### 3.1 阅读卡片与排版

- 论文标题、摘要、详情、文献引用与操作区域统一间距、背景、边框和移动端 padding，降低原先边框贴字的问题。
- 论文库、阅读详情及研究分析卡片的数学表达式由新增本地 `math_render.js` 转换为 MathML。支持常用 `$...$`、`$$...$$`、`\\(...\\)`、`\\[...\\]`、上下标、分式、平方根、基础希腊字母、常见算符与重音标记。
- 公式内容通过 `textContent` 与 DOM 文本节点处理，不对来源文本执行 `innerHTML`，不引入公共 CDN。非法或超限的表达式保留原文。
- **范围说明：** 当前为常见 TeX 表达式兼容层。复杂 `align`、矩阵、`\\begin{}` 环境及宏包扩展仍可能需要完整的离线 KaTeX/MathJax 排版引擎，不能宣称已支持全部 LaTeX。

### 3.2 摘要缺失

- 本地和公网文献卡片缺摘要时展示“从公开来源补取摘要”。
- 对已有合法 arXiv ID、DOI 的论文，向固定的 arXiv、Crossref、OpenAlex 公共接口查询原始元数据；设置超时和数据量上限，禁止任意跳转。
- 补到原始摘要才写入数据库，并清理相应的旧摘要缓存；保留原始题录、收藏和阅读笔记。
- 来源没有摘要时明确提示；不会由模型编造所谓“原始摘要”。部分会议预印本、出版社索引及被限制的记录确实可能没有可公开获取的摘要。

### 3.3 研究分析

- 中文问题通过有限的中英术语映射匹配英文标题及摘要，处理神经算子、复杂几何、非结构化网格、泛化、边界条件等常见研究表述。
- 在“已确认结论”之外单独提供题录候选、来源说明、公开摘要片段、核对维度及论文阅读链接。
- 增加几何/网格变化、外推泛化、物理约束及实验可比性的阅读检查路线。
- 本地用户在完成模型授权后，可以使用模型辅助生成**需要检查的问题**。模型只允许引用实际输入的候选论文编号，越界编号和擅自给出的数值结论被拒绝。
- 已确认结论仍必须来自当前有效的、经过人工确认的 PDF 原文依据。自动候选不会混入正式实验比较。

### 3.4 检索词生成

- JSON 正常时直接采用经验证的英文检索词。
- 模型输出有 Markdown 标记、自由文本、枚举列表或 JSON 数组时尝试恢复其中合法的英文检索词。
- 模型返回无法处理的文本时，仅根据用户已输入的已知科研术语给出显式标记为“本地词组建议”的结果。无法匹配则返回明确的错误提示。
- API 密钥缺失、数据发送未授权、模型通信失败分开处理，不会被伪装为检索词解析成功。
- 完整失败会带 `code` 和 `request_id`，可和运行诊断对照。

### 3.5 日志与控制台

- `BrokenPipeError`、`ConnectionResetError` 和 `ConnectionAbortedError` 归类为 `CLIENT_DISCONNECTED`，避免再次尝试写入已断开的连接。
- 真正的 SQLite 异常仍进入数据库故障路径，记录错误编号和调用位置。
- “设置 → 运行记录”新增近期日志汇总：HTTP 错误、模型错误、客户端断连、超过五秒的请求，以及常见错误码出现次数。
- 下载的运行诊断 ZIP 加入 `summary.json`，并保留原有 `runtime.jsonl` 和 `manifest.json`；所有统计只覆盖有限的最近记录。
- 诊断中不记录 API Key、完整研究问题、论文正文或 HTTP 请求体；包含可选历史任务日志时仍提醒用户先检查内容。

## 5. 完成当前故障后的实机检查顺序

1. 安全退出旧版本，确认新的工作台页脚为 v1.49.2，原数据目录保持不变。
2. 在“设置 → 模型连接”核对 API Key、模型名称和数据发送授权。点击“生成检索词”后，确认界面能区分模型结果和本地词表建议。
3. 在论文库挑选一篇已知无摘要的 DOI/arXiv 论文，点击“从公开来源补取摘要”，核对来源与返回内容。
4. 在研究分析中输入“神经算子在不同网格与复杂几何条件下的泛化限制”，检查候选论文、摘要片段、阅读路线；若仍无人工确认依据，应明确提示缺口。
5. 进入“设置 → 运行记录”刷新摘要，下载日志 ZIP，核对 `summary.json` 是否呈现最近错误类型和数量；若存在错误编号，按该编号在 `runtime.jsonl` 查询。
6. 对同一篇有完整 PDF 的论文，打开阅读与公式，检查可见的 PDF 页码、原文和引用，必要时人工确认结论再做跨论文比较。
