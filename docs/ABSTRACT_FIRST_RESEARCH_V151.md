# v1.51.0 研究分析与真实文献库试点

## 用户操作：四步完成摘要分析

1. 打开“研究分析”。首页只需输入一个明确的问题，例如“神经算子在跨网格与跨几何泛化方面采用了哪些方法，摘要报告了什么结果和限制？”。
2. 阅读输入框下方“已收录 / 摘要较完整 / 待补全”统计。如果有明显缺失或截断，点击“补全摘要”。系统把任务加入后台队列，逐篇调用公开元数据接口；完成后再点击“开始分析”。
3. 点击“开始分析”。即使没有 PDF、没有配置模型 API，也会显示题名和摘要所支持的研究方法、实验设置、作者声称的结果、局限与相应原句及论文链接。论文与原文引用标为“待核对全文”。
4. 需要比较论文中的具体实验误差、参数、数据划分或方法优劣时，展开下方“高级工具：PDF 实验数值核对与试点评估”。选择高相关论文，执行批量下载、全文索引、候选抽取、人工确认，并逐项核对跨论文对照组。

模型辅助默认可选，但研究分析没有模型授权也可以正常运行。模型辅助需在“分析设置与历史记录”展开项中确认本次向服务商发送的内容，未经授权不会发出研究问题和论文摘要。调用模型后，中文解释只允许引用本次提供的具体摘要原句；任何模型生成的结果都标为“待核对”。

## 摘要元数据处理规范

- 按 arXiv Atom、Crossref、OpenAlex 的公开原始元数据取摘要。来源如果未收录摘要，会记录为“不可补全”，不会用生成式摘要伪造原作者摘要。
- 短摘要仅提示“可能不完整”，因为某些学科确实存在简短的正式摘要。已较完整的摘要默认不会覆盖。下载失败按论文隔离，保留已经收录的摘要。
- `GET /api/abstracts/quality` 获取当前主题摘要质量，`POST /api/abstracts/start` `{"limit":60}` 触发后台补全。写操作受本地来源及安全令牌校验保护。
- 数据库的 `abstract_enrichment_runs` 与 `abstract_enrichment_attempts` 记录下载来源、长度、质量变化、错误类型、耗时及任务编号，不保存完整模型 Prompt 或 API Key。

## 真实试点评估：四个指标

| 指标 | 分子 / 分母及限制 |
|---|---|
| PDF 获取率 | 实际纳入批量任务的去重论文中，磁盘上有**有效 PDF** 的数量 / 纳入论文数。仅网页可访问不计成功下载 |
| 实验字段准确率 | 审核者明确给出“正确/错误”的**原始模型/规则提取字段**中，正确字段数 / 已判定字段数；人工修改后结果单独保存 |
| 人工核对耗时 | 有人工主动计时记录的审核操作总秒数，以及有记录的每次审核平均秒数。程序处理时间不计入 |
| 有效跨论文对照组 | 至少两篇论文的指标定义、数据集版本、划分、单位/尺度、任务/几何、预算及随机种子全部经人工确认的对照组数。仅同名指标不算有效 |

此外，导出会包含全文索引成功数、待审核/已审核字段、文献摘要质量分布、来源异常分类。没有真实任务或独立人工标注时对应比例写 `null`，不以 0% 或假定通过替代。

## 在现有 60 篇真实论文上执行

项目源码附带的 `data/papers.sqlite3` **没有那 60 篇论文**。根目录仅保留两个正式启动脚本，试点导出脚本放在 `tools/` 目录。请在本机启动连接已有数据目录的 Paper-Radar，避免将空的示例数据库覆盖原有数据。运行“研究分析”检查摘要质量 → 补全摘要 → 开始分析。再选高相关论文开展 PDF 批量准备与审核。用户可在“高级工具”展开试点评估和下载 ZIP。

如需不依赖浏览器导出数据：

```bash
python tools/export_pilot_audit.py --db "/path/to/existing/papers.sqlite3" --topic default --output pilot_audit.zip
```

导出包括 `summary.json`、`papers.csv`、`field_review.csv`、`comparison_groups.csv`、`HOW_TO_READ.txt`。含论文题录和审核意见，外发前请检查隐私。

## 当前验证边界

- 隔离测试验证摘要分组、元数据补取、HTTP/SQLite、实验字段与审核统计；前端 1280/390 像素布局经 Chromium 检查。
- `pilot_references/public_pdf_access_checks.csv` 包含 11 篇真实公开 arXiv PDF 的**网页可读取性**核查，9 篇可读取，2 篇被网页解析器文件大小限制拦截。这不能计算为本地软件下载率。
- `pilot_references/hand_checked_real_table_values.csv` 为两篇实际论文的 11 条人工 PDF 表格参考数值；尚未由用户本机软件抽取，不能证明系统字段准确率。
- 用户现有的 60 篇文献库、授权模型调用、实际审核者计时记录在本轮环境中都不可用；不能伪称完成真实用户 60 篇试点。需导入或本机导出评测包后做正式量化分析。
