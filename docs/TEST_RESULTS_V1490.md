# Paper-Radar v1.49.0 测试与审阅结果

**测试日期：2026 年 11 月 10 日。版本定位：研发验证版。**

| 项目 | 结果 | 适用范围 |

## 测试方式说明

- 第一次批量回归由于测试运行脚本设置了全局 `PAPER_RADAR_USER_HOME`，覆盖部分测试自行创建的临时数据目录，导致历史启动模式断言失败。去除该全局覆盖，分别使用隔离的 `HOME` 重跑两个完整批次，均得到 432 passed；原失败属于测试执行环境冲突。
- 浏览器环境不允许 Chromium 直接访问本机 HTTP Origin，因此自动化使用已渲染页面及测试专用请求桥接访问隔离 HTTP 服务。涵盖业务接口与数据库状态，但不能证明浏览器原生导航、Cookie/下载、PDF 原生嵌入渲染在目标设备上均有效。
- 新增 `tests/test_v1490_reading_wizard.py` 覆盖中文问题匹配英文原文的限定词表、未建立索引时的明确提示、PDF 指纹变化、研究问答引用编号、模型编造数值拦截、权限隔离和向导挂载。
- 模型连接预设密钥在测试中均为虚拟数据。未调用真实收费模型、未对外部学术数据库进行在线稳定性或订阅授权验证。

## 交付前保留的验证边界

1. 至少 5 位实际非开发用户独立完成首次使用任务并留下匿名结果后，才能计算成功率、用时中位数、错误次数和求助率；本次没有此类真实样本。
2. 真实模型 API 连接、费用和同意流程需在目标部署环境中用小额预算验证；不得上传未授权研究内容。
3. Windows/macOS/Linux 安装、浏览器原生 PDF 阅读、网络论文搜索和 GitHub 发布仍需要各自的正式验收。
4. 引用编号和数值检查降低模型凭空生成数据的风险，不能代替科学事实核验、表格条件比较和人工结果验证。
