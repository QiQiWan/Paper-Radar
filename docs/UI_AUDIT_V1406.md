# Paper-Radar v1.40.6 · 全页面 UI 审查与验收

## 调整范围

本次保持原有检索、后台任务、论文记录、Zotero、报告导出和鉴权逻辑，统一界面表现。主界面覆盖工作台、论文库、任务中心、研究跟进、研究助手、研究报告、设置、Zotero 研究方向及 PDF 下载；另外检查公网端和帮助文档。

## 主要问题及修复

| 范围 | v1.40.5 问题 | v1.40.6 处理 |
| --- | --- | --- |

| 间距 | 不同页面的表单、卡片和按钮间距不一致 | 引入 4/8/12/16/24/32px 间距变量及统一圆角、控件高度 |

## 视觉规范

- 全站字体使用系统中文、英文默认 UI 字体；无需打包商业字体。
- 标准正文 15–16px；小提示原则上 13px 起；论文标题 16px，章节标题 19px，页面标题约 28–32px。
- 主操作按钮与输入控件高度约 42–44px；标签和次级按钮根据功能允许紧凑，但需保证可点击性。
- 以白色卡片、灰白背景、深蓝正文和稳健的蓝色交互色为主；不增加大面积渐变和装饰。
- 保留深色主题、键盘焦点轮廓、屏幕尺寸适配以及偏好减少动态效果的兼容性。

**验收边界：** 当前的视觉截图使用项目真实 HTML/CSS 和模拟论文条目，通过容器内 Chromium 渲染。容器浏览器导航策略限制了直接访问本机 HTTP UI，因此当前数据截屏并不等同于用户 Windows 电脑上的实机联网与整流程验收。数据库、任务执行与 API 行为未因这轮视觉迭代发生变更。

## 复现视觉审查

如需在开发环境重跑静态页面视觉截图，可安装可选检查依赖 BeautifulSoup、Playwright 和 Chromium，然后运行 `UI_TAG=review python tools/ui_visual_audit.py`（Windows 请设置对应环境变量）。这项脚本仅用于界面截图验证，不需要连接论文检索 API，脚本依赖不属于日常运行依赖。

## Windows 升级步骤

1. 结束旧版任务与后台服务，备份论文库、设置与 PDF 文件。
2. 从 v1.40.5 升级时可使用增量补丁；更早版本建议使用完整源码包。
3. 解压到新目录，或将补丁中对应文件覆盖旧源码。不要覆盖用户数据目录。
4. 双击 `start_windows.bat`；在浏览器中使用 `Ctrl+F5` 清除旧 CSS 缓存。
5. 进入论文库检查“筛选与批量操作”折叠状态、论文卡片阅读状态和个人笔记；随后检查工作台、设置、任务中心及底部浮动面板。
6. 如果仍看到旧尺寸，核对页脚版本是否为 `v1.40.6`，并确认启动的是新源码目录。
