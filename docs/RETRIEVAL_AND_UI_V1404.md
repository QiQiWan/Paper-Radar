# v1.40.4 检索与任务面板更新

## 更新方法

1. 停止旧版 Paper-Radar 服务，退出当前浏览器中的旧页面；不要在任务运行时直接替换代码。
2. 备份现有论文库、配置和重要 PDF。研究数据通常保存在 Windows 的 `%LOCALAPPDATA%\Paper-Radar`，与程序目录分开。
3. 将完整源码解压到新的文件夹，双击根目录的 `start_windows.bat`。保留此前的数据目录，不复制旧版的 Python 缓存或虚拟环境。
4. 在浏览器按 `Ctrl+F5` 强制刷新静态资源。如果页面仍显示旧样式，确认服务进程已从新目录启动。

## 检索与额度

- OpenAlex 可通过“设置 → 文献来源授权 → OpenAlex”填写免费 API Key。保存后点击“检查 API 额度”，按需读取官方剩余额度提示。该操作不会公开保存的 Key。
- HTTP 429 时按服务端等待提示判断是否重试；不得在长时间限流后立即循环请求。来源失败不阻断 arXiv、Crossref、OpenReview。
- OpenAlex 语义搜索使用年份过滤，并在本地执行精确日期判断。常规与语义检索共享服务商额度。
- OpenReview 可能因公开投稿状态、检索词和回溯天数限制得到 0 篇。复合词查询完全无命中时会进行一次受限补检，候选必须仍与原始检索词一致。

## 底部任务面板

- 新任务开始后，右下角显示任务阶段、进度和简短状态，不再占用页面顶部。
- 任务未自动展开时可点击“查看详情”向上打开详情，可查看来源状态、每个处理阶段的论文数量、运行日志和按需导出的诊断包。
- 点击“最小化”或按 `Esc` 保持任务继续执行。任务完成后可点击 `×` 隐藏本轮通知；历史仍保存在任务中心。页面刷新后会再次读取最近任务记录。
- v1.40.5 起新任务默认展开，用户可立即最小化，查看页面正文。手机浏览器采用窄屏底部样式；底部导航与输入控件仍建议通过滚动访问。

## 验收步骤

1. 仅选择 arXiv 进行 7 天内关键词检索，确认底部面板出现、显示进度、能展开和收起，检索成功后可隐藏。
2. 选择 Crossref 和 OpenAlex，再查看来源结果和“本轮检索数量明细”。达到数量上限应显示成功及待补检状态，HTTP 429 应提示限流及服务端等待线索。
3. 如果 OpenAlex 返回 429，先执行官方额度检查或配置免费 Key；若持续限流，请稍后再试，不应反复触发短时间请求。
4. 在移动浏览器打开相同任务，检查底部条、抽屉、日志滚动及横向溢出。按 `Ctrl+F5` 更新样式。
5. 如检索依旧失败，双击 `CHECK_RETRIEVAL_WINDOWS.bat` 检查来源；从任务面板导出检索诊断包。诊断包不包含 API Key 或关键词。

## 自动测试的边界

离线回归验证额度退避、语义检索年份过滤、来源记录与任务展示。环境受限时无法证明 OpenAlex 实际账户的剩余额度、用户 Windows 代理/证书配置或所有外部来源当前均可正常联网。需要按以上实机步骤补充验收。


## v1.40.5 任务面板交互补充

- 检索任务面板默认放大显示，桌面端最大宽度提升至约 580px。
- 新任务开始后面板会自动展开，便于用户和旁观者直接确认系统正在工作。
- 面板保留“最小化”按钮，用户可随时收起，不影响后台任务继续执行。
- 移动端面板同步放大，并提高展开后的可视高度。
