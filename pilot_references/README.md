# 公开真实论文核查样本（与本机试点分开）

- `public_pdf_access_checks.csv`：对先前研究简报中 11 个 arXiv PDF 链接做公开网页 PDF 文本读取核查，9 个可在网页工具中提取正文，2 个因网页工具文件体积上限失败。**这里的 9/11 不是 Paper-Radar 本地下载成功率**，也不能据此计算用户 60 篇文献的 PDF 获取率。
- `hand_checked_real_table_values.csv`：人工对照两篇公开论文的 PDF 表格建立的 11 条参考数据。PI-Init 论文表 5 位于 PDF 第 13 页；CoupledFlow 表 1 位于 PDF 第 9 页。数值记录包括表中倍率、训练样本数和模型名称，避免跨单位或跨训练预算误用。
- 手工对照数据仅用于将来检查算法提取的结果，**未通过当前实际代码中的 PDF 下载和字段抽取链路，也不能据此宣称模型字段准确率**。
- 如后续本地文献库下载到了相同版本 PDF，仍需要使用 PDF SHA256 和页码进行对应核查，避免论文更新版本造成页码、数值变化。
