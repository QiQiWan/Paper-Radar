# 人工评估与仲裁规范

## 1. 标注流程

1. 审核员 A、B 各自打开 `manifest.json` 指向的版本固定 PDF，核对摘要、实验部分、附录和图表。
2. 两名审核员分别填写 `annotations/review_A.csv` 和 `review_B.csv`，不得相互复制答案。填写 `decision=accepted/rejected/needs_recheck`。
3. 每条证据必须检查文件 SHA-256、物理页码（从 1 开始）、原文引文、表格行列、方法、数据集、指标、数值、单位、基线和实验条件。
4. “同页出现某个指标与数字”不能直接视为有效实验指标；存在多行、多列或多模型时，必须核查该数值属于哪种方法和数据集。跨页信息必须分别记录页码。
5. A/B 结论不一致或任一给出 `needs_recheck`，在仲裁表中说明差异并记录最终证据；仲裁员不可依照模型推荐自动通过。
6. 对跨论文配对，分别填写数据版本、划分、测量口径、单位、指标方向、训练预算和统计聚合；任何关键条件缺失均保留 `unverified`。
7. 对研究问答，审核员给出简洁可核查的 `answer_gold`、准确的 citation、答案是否可由当前证据支持；答案可明确为“原文未给出”。

## 2. 证据字段口径

- `verified_quote`：原文文本是否与当前 PDF 对应页一致；原文中有数字也不说明其归属已核对。
- `relation_correct`：指标—数值—方法—数据集的同一行列关系是否成立，必须查看页面的真实表格布局。
- `metric_correct` / `value_correct`：字段与原文是否匹配，不仅是文字相邻。
- `correct_setting`：完整实验条件，包括数据版本、网格/时间步、样本数、切分方式、硬件/预算或相关约束。
- `decision=accepted`：本条记录经过当前审核员核验；至少两人一致或仲裁通过才可视为人工金标准。

## 3. 跨论文可比性

可比须满足任务对象、数据来源及版本、train/test 划分、指标含义及方向、单位、统计聚合、样本数/算力预算及相关实验约束。部分条件一致则只能列为候选。

如果数据集、单位或任务不同，通常归为不可直接定量比较；不要因为两篇论文都使用 FNO/DeepONet 或指标名称均为 MSE 就计算“性能提高”。

## 4. 冲突识别

`contradiction_label` 可填写 `confirmed_conflict`、`apparent_conflict_due_to_settings`、`no_conflict`、`insufficient_evidence`。只有两个命题在同一实验语境下互相排斥，才能确认冲突。对模型主张不同但条件不同的情况，判为“条件不同造成的表面分歧”。

## 5. 研究问答评分

建议 0–3 级人工评分：3=所有关键事实均受引文支持、条件充分；2=核心正确但少一项非关键条件；1=部分正确但遗漏重要限制；0=无依据或错误。引用必须包含论文版本和 PDF 物理页码；无证据时回答“不足以判断”可得满分。

记录人工完成用时、修正字段数，计算机器预标注的人工修订率。按论文划分训练/验证/测试，避免相同论文的不同片段泄漏到不同集合。

## 6. 数据质量发布条件

建议正式基线至少有 30 篇 PDF、每篇 2 条可核查证据、每类任务 20 个问题或配对（具体以真实材料可用性为准），两名研究者复核并完成分歧仲裁；若可比正例或冲突正例不足，应继续扩充论文样本，不得仅以负例完成验收。
